# AGENTS.md

## Agent skills

### Issue tracker

Issues live in It's a Plan, project `PRB` (via the `itsaplan` MCP server). See `docs/agents/issue-tracker.md`.

A PR that delivers an issue has `Closes PRB-<n>` in its body: that is what moves the card to `Done` on merge.

### Triage labels

Triage roles map to `PRB` columns, assignees and the `Planning` label (for needs-info). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
